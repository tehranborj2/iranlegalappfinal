## نکته مهم

فایل‌های این بسته را در ریشه یک Repository خالی قرار دهید. فایل‌های نسخه قبلی را روی آن Merge نکنید.

## Workflowها

- `Build Android Test APK`: ساخت APK تستی
- `Build Signed Release APK and AAB`: ساخت خروجی انتشار با چهار GitHub Secret

کنترل‌های سخت‌گیرانه و شکننده منابع عمداً حذف شده‌اند. Workflow فقط پروژه را آماده می‌کند، Gradle را اجرا می‌کند و وجود خروجی را بررسی می‌کند.

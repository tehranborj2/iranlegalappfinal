# Iran Legal Android 1.0.4

نسخه مینیمال و پایدار برای Build در GitHub Actions.

- آیکون اختصاصی ایران لگال
- صفحه سفید با لوگوی کامل در شروع تازه برنامه
- عدم نمایش مجدد Splash هنگام بازگشت از ابزار
- Back در صفحه‌های سایت/ابزار: بازگشت به خانه محلی برنامه
- Back در خانه برنامه: انتقال برنامه به پس‌زمینه
- versionName: 1.0.4
- versionCode: 10

## نکته مهم

فایل‌های این بسته را در ریشه یک Repository خالی قرار دهید. فایل‌های نسخه قبلی را روی آن Merge نکنید.

## Workflowها

- `Build Android Test APK`: ساخت APK تستی
- `Build Signed Release APK and AAB`: ساخت خروجی انتشار با چهار GitHub Secret

کنترل‌های سخت‌گیرانه و شکننده منابع عمداً حذف شده‌اند. Workflow فقط پروژه را آماده می‌کند، Gradle را اجرا می‌کند و وجود خروجی را بررسی می‌کند.

## تشخیص درخواست‌های اپ در سایت

WebView اپ عبارت زیر را به User-Agent اضافه می‌کند:

```text
IranLegalApp/1.0.4
```

این شناسه برای مخفی‌کردن عناصر مخصوص وب، مانند باکس تماس پایین سایت، استفاده می‌شود.
